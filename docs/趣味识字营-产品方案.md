# 趣味识字营 — 产品方案（生动 · 趣味浓）

> **文档目的**：对齐首页入口「边玩边记，闯关拿星」的初衷（见 `docs/原始设计.md` 卡片2），给出**可评审、可分期落地**的玩法与体验方案。  
> **受众**：以 **3～8 岁（幼儿园大班～小学低年级）** 为主，**常由家长短时陪同**；注意力短、怕挫败、以形象与声音记忆为主。  
> **说明**：下文「趣味浓」指玩法与反馈足够好玩、有层次；若产品希望强化 **田园 / 农场** 世界观，可在二期作为「皮肤 + 文案包」叠加上去，不改变核心玩法骨架。

---

## 一、初衷与定位（和课本同步学的关系）

| 维度 | 课本同步学 | 趣味识字营 |
|:---|:---|:---|
| 心智 | 「我要跟上学校」 | 「我在玩，顺便记住了」 |
| 节奏 | 按课、按字表，偏系统 | **短关卡**（1～3 分钟），可随时停 |
| 难度 | 与课内一致 | **略游戏化**，允许重复练、无「挂科」压力 |
| 数据 | 强绑定识字表/写字表 | **弱绑定**：可从当前年级字池抽题，**不替代**课内测评 |

**一句话**：识字营是 **课外的「游乐场」**，用闯关、动画、即时反馈把「音—形—义」练熟；课内权威仍以「课本同步学 + 字卡 + 小测」为准。

---

## 二、受众画像与体验原则（幼儿向清单）

1. **一步一事**：一屏一个主动作（大按钮），说明不超过一行童化短句。  
2. **先好玩再正确**：允许试错；错用**表情/音效/颜色**轻提示，不用红叉大字「错了」。  
3. **短回合**：单关 30～90 秒；整轮「营」建议 **5 关内**结束，给「我赢了」的闭环。  
4. **强反馈、弱比较**：星星、贴纸、萌萌一句话；**不做**全服排行榜、不做「比别人差」。  
5. **家长可控**：无社交压力、无强制麦克风；录音类玩法默认关或放二级。  
6. **可访问**：字够大、对比够、可只听不读；无音频时降级为「看形选义 / 描一笔」。

## 三、世界观与界面气质（生动从哪里来）

**主 IP**：沿用首页 **萌萌（熊猫）** 当营长——每关开场一句「跟我来！」，结算一句「你太棒啦 / 再来一小关」。  

**场景包装（任选其一做主视觉，其余做关卡皮肤）**：

- **气球营地**：关卡是「升起气球」，每对一题气球亮一颗星（与首页 🎈 一致）。  
- **小火车识字号**：车厢一关一节，到站撒花。  
- **可选二期**：**开心农场**——「帮蔬菜找名字」「听音摘果子」，与「趣味农」谐音梗可做营销皮肤，**不绑死**一期技术实现。

**音画节奏**：进入营内先 **3 秒「营地 BGM」淡入**（可关）；每关胜利 **短音效 + 粒子/贴纸飞入**（H5/App 能力内选轻量实现）。

## 四、玩法矩阵（闯关 = 多玩法串关）

建议首页点进「识字营」先到 **营地大厅**：3～4 个「游戏屋」图标 + 今日推荐一条；孩子点任一屋进入**随机 3～5 关微串关**，关间用「走路画」连接（脚印/车厢），数字为辅。

### 4.1 关卡类型（与现有能力对齐，易复用）

| 关卡名（童化） | 核心能力 | 玩法摘要 | 与现有代码关系 |
|:---|:---|:---|:---|
| **耳朵捉字** | 听音辨形 | 听一遍 → 2～3 个大字点选 | 可复用 `lesson-dictation` / `lesson-quiz` 听音逻辑 |
| **字形连连看** | 形近辨析 | 字与图/字与拼音配对，限时宽松 | 新做轻量配对 UI |
| **萌萌跟读角** | 音形联结 | 单字大字 + 再听一遍（拼音优先） | 可跳转或内嵌 `lesson-follow` 单字模式 |
| **星星配对赛** | 复习巩固 | 两列打乱，点一对消 | 经典配对，字池小（4～6 对） |
| **笔顺小挑战（轻量）** | 书写准备 | 只练 1～2 笔或描红一笔 | 可 deep link 到 `stroke` 或自研轻描 |

**关底 BOSS（每轮最后一关）**：固定为 **「耳朵捉字」或「星星配对」** 之一，让孩子有「打 BOSS」的仪式感，规则仍简单。

### 4.2 难度与字池

- **字池来源**：默认 **当前年级 + 学期 + 教材偏好** 下随机抽字；可混入 **「我经常错的」** 一字一关（与 `wrong_count` 弱联动）。  
- **难度阶梯**：同一玩法内用 **选项个数**（2 选 1 → 3 选 1）与 **是否显示轮廓提示** 调节，而不是加文字说明。

## 五、激励与进度（趣味浓但不焦虑）

- **营内货币**：只用 **「营星」**（与课次字卡星星概念区分，避免家长混淆——界面文案写「游戏星星」）。  
- **成就**：贴纸册（收集 5 张贴纸换一句萌萌语音），**不**与课内「已学」强制挂钩。  
- **每日入口**：首页可写「今日营地：气球关 ×3」，与「每日一练」错开：每日一练偏复习，识字营偏 **玩**。

## 七、文案与命名（避免压力词）

- 多用：**玩一玩、选一选、听一听、帮帮忙、点亮、收集**。  
- 少用：**考试、必须、闯关失败、排名**。  
- 失败关：**「再试一次也很棒」** + 自动再给一次提示（与课次听写设计一致）。
