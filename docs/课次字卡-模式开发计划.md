# 课次字卡：听写 / 小测 — 开发计划

> **2026-05 更新**：课卡入口现为 **听写 + 小测**；跟读专用页仍保留文件但默认无入口。拼音点读见字卡拼音行（本地 opus）。
>
> 依据：`docs/课次字卡-跟读与听写模式设计.md`、`docs/课次字卡-学习进度与小测设计.md`、`docs/原始设计.md`。
> 原则：**先打通小测 MVP（可验收）→ 课级进度 → 听写**，每步可独立发版。

---

## 总览（阶段依赖）

```
阶段 0 路由与传参
    ↓
阶段 1 本课小测 MVP（听音三选一 + 错题计数 + 结算）
    ↓
阶段 2 课级进度（小测通过时间等，可选 storage）
    ↓
阶段 3 跟读专用页（与拼音页解耦）
    ↓
阶段 4 听写专用页（听音点字 MVP）
    ↓
阶段 5 家长报告 / 设置开关 / 题型扩展
```

## 阶段 0：路由与课次 → 小测传参 ✅（与第一步实现一并交付）

| 任务 | 说明 | 验收 |
|:---|:---|:---|
| `pages.json` 注册 `pages/literacy/lesson-quiz` | 标题「本课小测」 | 能打开空白页 |
| `utils/lesson-mode-session.js`（或同名） | `put` / `take` 一次性 payload，避免 URL 过长 | 进页后能读到字表；读后清除 |
| `lesson.vue` `onMiniQuiz` | 写入 payload 再 `navigateTo` lesson-quiz，带 `rjLesson` 或 `hint` | 从人教课次 / hint 课次均可进 |

## 阶段 1：本课小测 MVP（设计文档 §2.3 / §2.4）

| 任务 | 说明 | 验收 |
|:---|:---|:---|
| 字池与题量 | 本课 `rows`，随机 **min(5, N)** 题；**N&lt;2** 提示并返回 | 边界不崩 |
| 题型 `hear_pick` | 播目标字读音（`speakHanzi`），**3 选 1**（池≥3）或 **2 选 1**（池=2） | 选对进下一题 |
| 错题回写 | 最终答错调用 `addCharWrongCount(hanzi, 1)` | storage 中 `wrong_count` 增加 |
| 单题重试 | 同一题最多 **2 次**机会（与设计一致） | 第二次错后揭示并下一题 |
| 结算页 | 展示「对了 X / Y」、鼓励文案；**回字卡** | 返回后课次页仍在 |
| **不做的** | 本阶段不写 `mastered`、不写课级通过（留给阶段 2） | 代码中勿调用 |

## 阶段 2：课级学习进度（设计文档 §1.4）

| 任务 | 说明 | 验收 |
|:---|:---|:---|
| 新 storage `user_lesson_progress_v1`（或等价键） | 存 `lesson_key`、`quiz_passed_at_ms` 等 | 小测通关可写入 |
| 课次页角标/星星（可选） | 与小测通过弱绑定 | 产品确认规则后再接 |

**阶段 2 落地说明**：键名 `STORAGE_KEYS.USER_LESSON_PROGRESS`；`lesson_key` 由 `buildStoredLessonKey(rjIdx, hint)` 生成（`rj:n` / `hint:…`）；通关线与设计 §2.3 一致：**答对 ≥ ceil(0.8 × 题数)**；结算写入 `quiz_passed_at_ms`（仅达标时刷新时间）、`quiz_best_*`；课次页底部展示「本课小测已通过」文案（与星星/已学计数仍弱绑定）。

| 任务 | 说明 | 验收 |

| 新建 `pages/literacy/lesson-follow.vue` | 顺序播字 +「下一个」+ 可选录音（录音默认关） | `lesson.vue` 不再跳拼音首页 |

| 任务 | 说明 | 验收 |
|:---|:---|:---|
| 新建 `pages/literacy/lesson-dictation.vue` | 听音 **三选一** 点字 + 提示阶梯 | `onDictation` 跳转 |
