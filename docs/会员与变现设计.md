## 一、商业模型总览

**建议：订阅为主（70%～85%）+ 激励广告为辅（10%～20%）+ 可选单次 IAP（5%～15%）**

| 收入来源 | 适用场景 |
|---------|---------|
| **订阅会员**（微信 / Apple IAP） | 长期学习家庭：全年级、无限练习、去广告 |
| **激励视频广告** | 免费用户：多练一轮、多查几次、游戏复活 |
| **单次内购（可选）** | 开学季年级字库包、期末复习包 |

### 合规原则（儿童产品）

- 付费入口、价格、协议 **仅面向家长**（`pages/vip/vip.vue` 已有「家长须知」）。
- 儿童界面不出现「充值」「限时抢购」等压迫文案；统一「请家长帮忙开通」。
- 广告：非个性化、品牌安全、低频；避免学习中途强制插屏。
- 敏感操作前 **家长验证**（简单算术 / 长按设置入口）。

## 二、免费 vs 付费功能矩阵

### 2.1 永久免费（获客与口碑）

| 模块 | 免费额度 | 说明 |
|------|---------|------|
| **查字** | 每日 15～20 次 | 工具拉新；**部首全年级检索**保持开放（已实现 `queryAllShiziCurriculumChars`） |
| **拼音浏览** | 声母/韵母/整体认读点读 | 建立「能学」认知 |
| **首页示范「字」** | 完整体验 | 转化漏斗 |
| **课本同步** | **当前年级 + 当前学期** | 与校内进度一致 |
| **每日一练** | **1 轮/天**（约 8～10 字） | 养成习惯 |
| **勋章墙** | 基础勋章可见 | 激励留存 |

### 2.2 会员专享

| 功能 | 免费 | 会员 | 落点页面 |
|------|------|------|---------|
| 年级/教材切换 | 仅当前册 | 1～6 年级任意切换 | `pages/settings/curriculum` |
| 课本同步全课 | 当前课前后各 2 课 | 全部课次 | `pages/literacy/textbook` |
| 写字练习 | 3 字/天 | 不限 | `start-write-practice` |
| 笔顺动画 | 每字 2 遍/天 | 不限 | `lesson` / `hanzi-stroke-player` |
| 拼音跟读+评分 | 每日 5 次 | 不限 | `pages/pinyin/index` |
| 自动连读 | 不可用 | 可用 | `pages/pinyin/index` |
| 拼读练习「换一批」 | 3 次/天 | 不限 | `pages/pinyin/index` |
| 每日一练 | 1 轮/天 | 多轮 + 弱项计划 | `pages/literacy/daily` |
| 气球营 | 2 关/天 | 不限 | `pages/literacy/game` |
| 导出生字表 | — | 可打印分享 | `pages/me/learned` |
| 易错字/复习计划 | 仅 Top5 | 完整列表 | `pages/me/wrong-often` |
| 广告 | 有 | 无 | 全局 |

## 六、功能保护（技术实现）

### 6.1 三层防护

```
1. UI 层：灰显 +「请家长开通」
2. 路由/业务层：gateVipFeature() 进入前拦截
3. 服务端（上线后）：订单校验 + 权益 JWT，客户端仅缓存到期时间
```

### 6.2 统一门禁 API（待实现 `utils/vip-gate.js` 或扩展 `vip.js`）

```javascript
// 业务页统一调用
const g = await gateVipFeature('daily_unlimited', {
  freeQuotaKey: 'daily_rounds',
  freeLimit: 1,
  adUnlockAdds: 1
})
if (!g.ok) showParentPaySheet(g) // → /pages/vip/vip
```

### 6.3 本地配额 Storage Key

| Key 模式 | 含义 | 重置 |
|----------|------|------|
| `quota_daily_chars_YYYYMMDD` | 当日练习字数 | 每日 0 点 |
| `quota_dict_lookup_YYYYMMDD` | 查字次数 | 每日 |
| `quota_pinyin_follow_YYYYMMDD` | 跟读评分次数 | 每日 |
| `quota_drill_shuffle_YYYYMMDD` | 拼读换一批 | 每日 |
| `quota_game_levels_YYYYMMDD` | 气球营关卡 | 每日 |
| `vip_expire_at_ms` | 会员到期（已有） | 支付成功写入 |

会员激活后跳过配额；**上线后以服务端订单为准**，防改本地时间。

### 6.4 支付接入

| 平台 | 方案 |
|------|------|
| 微信小程序 | `wx.requestPayment` + 服务端统一下单 + 回调写 `vip_expire_at` |
| Android App | 微信/支付宝 |
| iOS App | Apple IAP（产品 ID 与 `VIP_PLANS.id` 一一对应） |
| 演示 | 保留 `requestPurchase` 模拟，上线替换 |

### 6.5 家长验证

以下操作前 `parent-gate`：

- 打开会员页、发起支付、关闭广告、切换全年级、导出字表。
