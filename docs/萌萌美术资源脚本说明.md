# 萌萌美术资源脚本说明

> 脚本目录：`scripts/`  
> 资源目录：`static/mengmeng/`、`static/tab/`  
> 改稿或新增资源后，可用本文命令单张处理；批量仍用 `npm run`。

## 环境

- Python 3
- 依赖：`pip install Pillow opencv-python-headless`（去水印需要 OpenCV）

## npm 快捷命令（批量）

在项目根目录 `hanzi` 下：

| 命令 | 作用 |
| --- | --- |
| `npm run assets:resize-mengmeng` | 按内置 `SPECS` 缩放全部萌萌资源 |
| `npm run assets:remove-watermark` | 按内置 `TARGETS` 去除豆包右下角水印 |
| `npm run assets:mengmeng` | 先批量缩放，再批量去水印 |

## 路径写法

以下三种均可（推荐第一种）：

- `static/mengmeng/ip/wave.png`
- `mengmeng/ip/wave.png`（相对 `static/`）
- 绝对路径（须在 `static/` 树下）

## 1. 查看 PNG 信息 `inspect-mengmeng-png.py`

```powershell
cd d:\workplace\uni-app\hanzi

# 单张
python scripts/inspect-mengmeng-png.py static/mengmeng/ip/wave.png

# 扫描全部 mengmeng + tab（不传参数）
python scripts/inspect-mengmeng-png.py
```

输出示例：`1200x1200 RGBA alpha=True | static\mengmeng\ip\wave.png`

---

## 2. 去豆包水印 `remove-doubao-watermark.py`

处理右下角「豆包AI生成」类水印；首次会备份到  
`static/mengmeng/_before-watermark-removal/<相对路径>`。

```powershell
cd d:\workplace\uni-app\hanzi

# 单张
python scripts/remove-doubao-watermark.py static/mengmeng/laba.png

# 单张，并同步处理 _source-2048 里同名文件（若有）
python scripts/remove-doubao-watermark.py static/mengmeng/laba.png --source-2048

# 批量（内置 TARGETS 列表 + 自动清理 _source-2048）
python scripts/remove-doubao-watermark.py
# 或
npm run assets:remove-watermark
```

---

## 3. 缩放 PNG `resize-mengmeng-assets.py`

保留透明通道；首次会备份原图到  
`static/mengmeng/_source-2048/<相对路径>`。

内置尺寸见脚本内 `SPECS`（logo、ip、tab 等）。**不在表内的文件**须用参数指定尺寸。

```powershell
cd d:\workplace\uni-app\hanzi

# 单张：使用 SPECS 预设（须在目录中）
python scripts/resize-mengmeng-assets.py static/mengmeng/ip/wave.png

# 单张：最长边不超过 N
python scripts/resize-mengmeng-assets.py static/mengmeng/laba.png --max-edge 1200

# 单张：缩进 W×H 透明画布内（完整显示，可能留白）— 适合 IP 图
python scripts/resize-mengmeng-assets.py static/mengmeng/laba.png --contain 240 240

# 单张：居中裁剪铺满 W×H — 适合背景图
python scripts/resize-mengmeng-assets.py static/mengmeng/hero-bg.png --cover 1500 1000

# Tab 图：跳过「近白 → 透明」
python scripts/resize-mengmeng-assets.py static/tab/home.png --no-key-white

# 批量（内置 SPECS 全表）
python scripts/resize-mengmeng-assets.py
# 或
npm run assets:resize-mengmeng
```

| 参数 | 含义 |
| --- | --- |
| `--max-edge N` | 长边 ≤ N，等比缩放 |
| `--contain W H` | 放进 W×H 框，透明底，居中 |
| `--cover W H` | 裁剪铺满 W×H（`hero-bg` 等背景） |
| `--no-key-white` | Tab 图标不抠白底 |

## 示例：`laba.png`（喇叭萌萌）

推荐顺序：**先去水印 → 再缩放到 240×240 → 检查尺寸**。

```powershell
cd d:\workplace\uni-app\hanzi

python scripts/remove-doubao-watermark.py static/mengmeng/laba.png

python scripts/resize-mengmeng-assets.py static/mengmeng/laba.png --contain 240 240

python scripts/inspect-mengmeng-png.py static/mengmeng/laba.png
```

确认输出为 `240x240` 且 `alpha=True` 即可。

若需铺满 240×240（可能裁边）：

```powershell
python scripts/resize-mengmeng-assets.py static/mengmeng/laba.png --cover 240 240
```

---

## 新图接入建议流程

1. 将 AI 导出大图放入 `static/mengmeng/...`
2. `remove-doubao-watermark.py <路径>` 去水印
3. `resize-mengmeng-assets.py <路径> --contain/--cover/--max-edge` 缩到目标尺寸
4. `inspect-mengmeng-png.py <路径>` 核对宽高与透明通道
5. 在 `utils/mengmeng-assets.js` 或页面中引用新路径

长期使用的尺寸可补进 `resize-mengmeng-assets.py` 的 `SPECS`，之后单张命令可省略 `--contain` 等参数。
