# 拼音点读 · 真机验收矩阵

发版前在下列环境各执行一轮（勾选通过）。重点：**快速连点以最后一次为准**、**切页停播**、**仅本地 opus（无 TTS 回退）**。

## 设备矩阵

| 平台 | 最低版本 | 必测机型/模拟器 | 通过 |
|------|----------|-----------------|------|
| 微信小程序 | 基础库 ≥ 2.30 | 开发者工具 + 1 台真机（Android 或 iOS） | ☐ |
| Android App | uni-app 发行包 | 1 台中低端（≤4GB RAM） | ☐ |
| iOS App | uni-app 发行包 | 1 台 iPhone（若上架） | ☐ |
| H5 浏览器 | Chrome / 微信内置 | 桌面 Chrome 抽测 | ☐ |

## 用例（每平台）

### A. 课次字卡 `lesson`

1. 字 A 播着时快速点字 B 拼音 → **只听到 B**  
2. 连续快速点 A/B/C → **只听到最后一次**  
3. 播着时返回上一页 → **立即停止**  
4. 无 opus 的字 → Toast「暂无…」或无声，**无系统合成音**

### B. 拼音 Tab `pinyin/index`

1. 各 Tab 手动点格：快速连点相邻格  
2. 开启「一起读」后中途点另一格 → 打断并播新格  
3. 切到其他 Tab → 连读停止  

### C. 课次小测 `lesson-quiz`

1. 听音题快速连点「再听」  
2. 播着时切到下一题 → 旧音不抢新题  

### D. 查字结果 `dictionary/result`

1. 连点喇叭  
2. 播着时点推荐字 → 播新字读音  

### E. 识字游戏 `literacy/game`

1. 自动播题音时快速点选项（应仍 hearLocked 或播完后可点）  
2. 多音节词高亮与读音一致  

### F. 乐园 + 大闯关

1. 声调/声母/韵母/整体认读 ear 页：连点「再听一遍」  
2. chart 页：快速点不同格子  
3. `pinyin/drill`：连点「再听一遍」  

### G. 写字练习 `write-practice`

1. 换字时上一字读音不叠在新字上
