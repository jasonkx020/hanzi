# 萌萌识字（hanzi）命名规格

本文档为 **hanzi** 项目的统一命名规范，与现有目录、`docs/APP架构重设计.md`、`docs/sqlite-schema.md` 及代码实践对齐。新代码应遵循本规格；存量命名可在改动相关文件时逐步收敛，不必一次性全量重命名。

---

## 1. 总则

| 原则 | 说明 |
|------|------|
| **可读优先** | 名称应表达业务含义（识字、拼音、课次、会员等），避免 `data1`、`helper2` 类缩写。 |
| **一致优先** | 同层同类资源使用同一套规则（见下文分表），不混用 `camelCase` 文件名与 `kebab-case` 文件名。 |
| **英文标识、中文展示** | 代码、路径、Storage 键、JSON 字段名用英文；界面文案、教材版本显示名、字表类型等用中文常量（见 `constants/curriculum-schema.js`）。 |
| **领域前缀** | 按业务域加前缀：`pinyin-`、`literacy-`、`meng-`（品牌 UI）、`vip-`、`dictionary-` 等，避免全局裸名冲突。 |
| **版本后缀** | 持久化结构变更时，Storage 键与 seed 文件名加 `_v1`、`_v2`，不原地覆盖语义。 |

**字符集**：路径与文件名仅使用小写英文字母、数字、连字符 `-`、下划线 `_`（下划线主要用于 snake_case 数据字段与少量历史键，见 §8）。拼音音频等特殊文件可使用带声调的 Unicode 文件名（`static/pinyin/`）。

## 2. 目录结构命名

| 目录 | 用途 | 命名规则 |
|------|------|----------|
| `pages/` | UniApp 页面入口 | 按 **业务域** 分文件夹：`home`、`literacy`、`pinyin`、`dictionary`、`me`、`settings`、`vip`、`tools`、`debug` |
| `components/` | 可复用 UI | 单文件组件，见 §4 |
| `utils/` | 无状态工具、算法、Storage 封装 | `kebab-case.js`；子域可建子目录，如 `utils/pinyin-tone-lab/` |
| `services/` | 编排多步流程、对外 API 封装 | `*-service.js` |
| `repositories/` | 读写持久化/数据源 | `*-repository.js` |
| `store/` | 全局响应式状态入口 | `*-store.js` |
| `constants/` | 常量、schema、文件名映射 | `kebab-case.js` 或 `snake_case` 仅用于与 DB/JSON 列名一致的 schema 文件 |
| `data/` | 静态配置列表（非用户数据） | `kebab-case.js` |
| `modules/{domain}/` | 领域用例 | `usecases/*.js`，动词开头函数 |
| `mixins/` | Vue mixin | `kebab-case.js` |
| `static/` | 打包静态资源 | 见 §9 |
| `scripts/` | 构建/数据处理脚本 | `kebab-case.mjs` / `.py` |
| `tests/` | 单元测试 | `*.test.mjs` |
| `docs/` | 设计/说明文档 | 中文标题 + `.md`，见 §12 |

**禁止**：在 `pages/` 下堆放与路由无关的 `.js` 逻辑文件（应下沉到 `utils/` / `services/` / `modules/`）。

## 3. 页面与路由（`pages.json`）

### 3.1 路径规则

格式：`pages/{域}/{功能}/[子功能].vue`

- **域（domain）**：与 Tab/主导航一致，如 `literacy`、`pinyin`、`me`。
- **功能（feature）**：`kebab-case` 英文，如 `write-practice`、`lesson-dictation`。
- **拼音实验室子域**：统一为 `{initial|vowel|tone|whole}-lab`，子页用短名：`index`、`ear`、`mouth`、`group`、`chart`、`match`、`body`、`mark`、`tip`。

示例（与现网一致）：

```
pages/home/home.vue
pages/literacy/lesson.vue
pages/pinyin/initial-lab/chart.vue
pages/settings/curriculum.vue
```

### 3.2 路由 path 与文件名

- `pages.json` 中的 `path` **不带** `.vue` 后缀，且与磁盘路径一致。
- 单页默认入口文件名为 `index.vue`；若域内仅一个页面，可用与文件夹同名的 `home.vue`（如 `pages/home/home`）。

### 3.3 导航 URL

- 代码内跳转使用 **绝对路径**：`'/pages/literacy/game'`（前导 `/`，与 `pages.json` 一致）。
- 查询参数：`camelCase` 键名，如 `?lessonId=3`（若新增参数，避免 snake_case 与 Storage 字段混淆）。

## 4. Vue 组件

### 4.1 文件名

- 一律 **`kebab-case.vue`**。
- **品牌/壳层组件**：`meng-` 前缀，如 `meng-page-nav.vue`、`meng-tab-hero.vue`。
- **拼音 UI**：`pinyin-` 前缀，如 `pinyin-lab-cell.vue`、`pinyin-four-lines-row.vue`。
- **识字/笔顺等**：语义化 `kebab-case`，如 `home-char-showcase.vue`、`tone-contour-card.vue`。

### 4.2 组件注册名

- `easycom` / 手动注册时，与文件名一致（短横线形式）。
- 模板中使用：`<meng-page-nav />`、`<pinyin-lab-cell />`。

### 4.3 单文件内部

| 种类 | 规则 | 示例 |
|------|------|------|
| `data` 字段 | `camelCase` | `currentGrade`, `isPlaying` |
| `computed` / `methods` | `camelCase`，动词开头 | `loadLesson`, `onTapChar` |
| 事件名（`$emit`） | `kebab-case` | `update:modelValue`, `lesson-complete` |
| Props | `camelCase` 声明；模板可用 kebab | `starCount` / `:star-count` |

## 5. JavaScript / 模块文件

### 5.1 文件后缀与放置

| 类型 | 文件名模式 | 导出约定 |
|------|------------|----------|
| 工具 | `utils/{name}.js` 或 `utils/{domain}/{name}.js` | 具名导出为主；极少数默认导出（如 `draw-native.js`） |
| 服务 | `services/{domain}-service.js` | `export function buildXxx`, `export async function fetchXxx` |
| 仓储 | `repositories/{domain}-repository.js` | `get*` / `update*` / `record*` |
| 状态 | `store/{domain}-store.js` | `get*State`, `refresh*State` |
| 用例 | `modules/{domain}/usecases/{verb}-{noun}.js` | 单入口函数，如 `startLiteracyGame` |
| 常量 | `constants/{topic}.js` | `export const UPPER_SNAKE` |
| Mixin | `mixins/{name}.js` | 默认导出对象 |

### 5.2 导入路径

- 优先使用别名：`@/utils/...`、`@/constants/...`（见 `package.json` → `imports`）。
- 相对路径仅用于同目录或紧邻兄弟文件，避免 `../../../` 超过两层。

### 5.3 函数与变量

| 种类 | 规则 | 示例 |
|------|------|------|
| 函数 | `camelCase`，动词开头 | `getQuotaState`, `playPinyinLocalAudio` |
| 变量 | `camelCase` | `progressMap`, `hanziList` |
| 布尔 | `is` / `has` / `can` 前缀 | `isVowelLevelUnlocked`, `canUseQuota` |
| 私有（模块内） | 可不导出；必要时前缀 `_` | `_normalizePrefs` |
| 类 | 极少使用；若用则 `PascalCase` | — |

### 5.4 常量

| 种类 | 规则 | 示例 |
|------|------|------|
| 配置/枚举 | `UPPER_SNAKE_CASE` | `STORAGE_KEYS`, `QUOTA_KEYS`, `SEMESTER` |
| 逻辑表名 | `UPPER_SNAKE` 字符串 | `TABLE_HANZI_CURRICULUM` |
| 列名字段映射 | `COL` 对象内 `snake_case` 键 | `COL.wrong_count` |

## 6. 数据模型与 JSON 字段

持久化（Storage、seed JSON、课本文案 JSON）字段统一 **`snake_case`**，与 `constants/curriculum-schema.js`、`docs/sqlite-schema.md` 一致。

| 字段示例 | 含义 |
|----------|------|
| `textbook_version_id` | 教材版本 |
| `grade`, `semester` | 年级、学期（学期值为中文 `上`/`下`） |
| `list_type` | 字表类型（中文枚举） |
| `hanzi`, `pinyin` | 汉字、拼音 |
| `learned`, `mastered` | 0/1 布尔 |
| `wrong_count`, `updated_at_ms` | 计数、毫秒时间戳 |
| `sort_order`, `lesson_hint` | 排序、课时提示 |

**内存对象**在应用层可使用 `camelCase`，但在 **写入 Storage 或 seed 前**应通过 schema/仓储层转换为 `snake_case`。

## 7. 本地 Storage 键

| 规则 | 说明 |
|------|------|
| 格式 | `{语义}_{可选域}_v{版本}`，全小写 `snake_case` |
| 集中定义 | 优先放入 `constants/curriculum-schema.js` 的 `STORAGE_KEYS`；域内专用可放在 `utils/*/constants.js`（如 `STORAGE_KEY_VOWEL_LAB`） |
| 版本 | 结构不兼容时递增 `_v2`，不复用旧键存新结构 |

示例：

```
curriculum_prefs_v1
user_char_progress_v1
vowel_lab_progress_v1
dictionary_detail_cache_v2
```

**避免**：`meng_dict_pending_hanzi` 与 `curriculum_prefs_v1` 混用多种风格；新键统一为 `snake_case` + `_vN`。

## 8. CSS 与样式资源

| 种类 | 规则 | 示例 |

## 9. 静态资源

### 9.1 目录

```
static/
  booktext/renjiaoban/     # 人教版课文 JSON
  pinyin/                  # 拼音读音 opus（文件名多为带声调拼音）
  voice/mengmeng/          # IP 语音提示
  mengmeng/ip|medals/      # 形象与勋章图
  tab/                     # Tab 图标
  fonts/                   # 字体与 LICENSE
  styles/                  # 全局 CSS
  images/                  # 通用插图
```

### 9.2 课本文案 JSON（`static/booktext/renjiaoban/`）

由 `constants/renjiao-textbook-filenames.js` 统一生成文件名，**禁止手拼字符串散落**。

| 类型 | 模式 |
|------|------|
| 课文主 JSON | `grade{1-6}-{up\|down}.json` |
| 识字/写字/词语/成语 | `grade{n}-{up\|down}-{literacy\|writing\|words\|idioms}.json` |
| 目录 | `grade{n}-{up\|down}-catalog.json` |
| 幼小衔接 | `preschool-bridge.json` |

### 9.3 萌萌语音（`static/voice/mengmeng/`）

- 格式：`{场景}_{动作/结果}.opus`
- 全小写 `snake_case` 英文，见 `docs/萌萌语音提示文案.md`

示例：`dictation_done_encourage.opus`、`pinyin_follow_good.opus`

### 9.4 拼音点读音频（`static/pinyin/`）

- 文件名：**与读音一致的带声调拼音** + `.opus`（项目既定规则，便于对照）。
- 轻读等特殊：可用 `men5.opus` 等约定后缀。

### 9.5 图片

- Tab/图标：`{name}.png` / `{name}-active.png`
- 勋章：`static/mengmeng/medals/m{两位数字}.png`，如 `m07.png`
- IP 表情：`static/mengmeng/ip/{emotion}.png`，如 `happy.png`

## 10. npm scripts 与脚本

| 种类 | 规则 | 示例 |

## 12. 文档（`docs/`）

| 类型 | 命名 |
|------|------|
| 产品设计 | 中文标题，如 `趣味识字营-产品方案.md` |
| 技术/API | `{主题}-{子主题}.md` 或中文，如 `拼音点读-播放会话API.md`、`sqlite-schema.md` |

## 13. 领域词汇表（推荐英文片段）

新增文件/路由时优先从下表选词，避免同义混用（如 `char` / `hanzi` 并存时：**数据字段用 `hanzi`，函数参数可用 `hanzi`；类型名可用 `Char` 前缀**）。

| 中文 | 英文片段 | 典型用法 |
|------|----------|----------|
| 识字（业务） | `literacy` | `pages/literacy/` |
| 汉字 | `hanzi` | `hanzi`, `speak-hanzi.js` |
| 拼音 | `pinyin` | `pinyin-lab`, `pinyin-play-session` |
| 声母/韵母/声调/整体认读 | `initial`, `vowel`, `tone`, `whole` | `*-lab` |
| 课次/课文 | `lesson`, `textbook` | `lesson.vue`, `textbook` |
| 听写/跟读/笔顺 | `dictation`, `follow`（或模式名）, `stroke` | `lesson-dictation` |
| 每日一练 | `daily` | `daily.vue` |
| 查字/字典 | `dictionary` | `dictionary-repository` |
| 会员 | `vip` | `vip-quota.js` |
| 萌萌 IP | `meng`, `mengmeng` | UI 用 `meng-`；资源目录 `mengmeng/` |
| 教材/课标 | `curriculum`, `renjiao` | `curriculum-db.js` |
| 勋章/成就 | `medal`, `achievement` | `medal-service.js` |

## 14. 快速对照表

| 场景 | 命名风格 |
|------|----------|
| 文件夹、`.vue`、`.js` 文件名（除 seed） | `kebab-case` |
| 函数、变量、props、data | `camelCase` |
| 导出常量、Storage 键名常量 | `UPPER_SNAKE_CASE` |
| JSON / Storage 值内字段 | `snake_case` |
| CSS 类 | `kebab-case` |
| 课本文案 JSON 文件名 | `grade{n}-{up\|down}[-suffix].json` |
| 数据库逻辑表名 | `snake_case` 字符串常量 |

## 15. 反例（避免）

```text
❌ pages/Literacy/Lesson.vue          # 勿用大写路径
❌ utils/pinyinUtils.js               # 勿用 camelCase 文件名
❌ components/PageNav.vue             # 应用 meng-page-nav
❌ userCharProgress                   # Storage 键勿用 camelCase
❌ static/booktext/五年级上.json       # 课文 JSON 勿用中文文件名
❌ utils/helper.js                    # 过于笼统
❌ getData()                          # 无领域语义
```

---

## 16. 变更流程

1. **新增命名**：先查本文档与 `constants/` 是否已有同义常量/工具。
2. **Storage 结构变更**：新键 `_vN`，保留旧键读取迁移逻辑，文档同步 `docs/sqlite-schema.md`。
3. **课本文案文件名变更**：改 `renjiao-textbook-filenames.js` + 脚本 + 文档，不单独改一处。
