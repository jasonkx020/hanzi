# 学习进度评估与课次小测 — 完整产品设计

> **文档目的**：定义「如何评估学习进度」与「课卡内小测如何设计与实现」的**产品主线、数据含义、交互流程与迭代边界**，与 `docs/原始设计.md`、`docs/课次字卡-跟读与听写模式设计.md` 一致，供评审与开发对照，避免进度口径混乱或小测与跟读/听写抢定位。  
> **与跟读/听写**：流程顺序与入口权重见 [课次字卡-跟读与听写模式设计.md](./课次字卡-跟读与听写模式设计.md) §5。  
> **当前实现锚点**：课次页 `pages/literacy/lesson.vue`（字卡、进度条、小测入口）；进度存储 `utils/user-progress-storage.js` + `constants/curriculum-schema.js` 中 `COL_PROGRESS`；小测当前为跳转 `pages/tools/stroke?mode=test` 的占位行为，本文档约定目标形态与迁移路径。

## 第一部分：学习进度如何评估

### 1.1 评估原则（幼儿向 · 与主线一致）

| 原则 | 说明 |
|:---|:---|
| **多信号、弱耦合** | 「看过」≠「会写」≠「测验对」；进度展示以**鼓励坚持**为主，不把单次测验当唯一真理。 |
| **可解释** | 家长与孩子能一句话说清「进度条代表什么」；避免黑盒算法。 |
| **本地优先** | 与现有架构一致：核心进度在 **uni.storage**（`USER_CHAR_PROGRESS`），不上传为默认。 |
| **与课绑定可选** | 字级进度已有教材维度；课级「是否完成小测」可增量存储，不破坏现有 key 结构。 |

### 1.2 进度维度（建议语义）

与现有字段对齐，并约定业务含义（实现时不得擅自改字段名，可扩展新键见 §1.4）。

| 维度 | 字段 / 来源 | 建议含义 | 典型更新时机 |
|:---|:---|:---|:---|
| **已接触 / 已学** | `learned === 1` | 该字曾进入「学过」状态（如打开过详解、或家长确认、或小测通过一题后策略配置） | 当前：`openChar` 等路径可写；建议：**小测不自动覆盖「未打开详解即已学」**，由产品开关决定。 |
| **掌握** | `mastered === 1` | 该字在**至少一种巩固方式**下达到稳定（如小测连对、跟读完成、听写点选对等，配置化） | 初期可与小测「本课通关」挂钩；远期可多条件。 |
| **薄弱** | `wrong_count` | 笔顺/小测等答错累计，用于「经常错的」排序 | 已有 `addCharWrongCount`；小测答错应调用。 |
| **课级完成度** | 见 §1.4 扩展 | 「本课字卡是否做完小测」等**聚合展示**，不替代字级记录 | 课次页星星、课本同步学列表角标等。 |

### 1.3 聚合层级（展示用）

| 层级 | 指标示例 | 用途 |
|:---|:---|:---|
| **字** | 已学 / 已掌握 / 错次 | 字卡角标、详情页、复习推荐。 |
| **课** | 本课 N 字中已学 M、小测是否完成、最近完成时间 | 课次页 `已学 M/N`、星星；课本列表可显示「已练」。 |
| **册** | 已学字数、完成课数 | 首页/统计；与 `hanzi_curriculum` 总字数对比。 |

**口径约定（防偏离）**：课次页当前「已学」= `learned===1` 的字数占比；若引入「仅点过小测未进详解」是否算已学，**必须在设置或家长区显式说明并默认保守**（仍以详解或明确动作为准更安全）。

### 1.4 数据模型（现有 + 建议扩展）

**现有（保持）**

- Key：`makeProgressKey(textbook_version_id, grade, semester, hanzi)`  
- 记录：`learned`, `mastered`, `wrong_count`, `updated_at_ms`

**建议扩展（可选、独立存储键，避免破坏旧 map 解析）**

- 新键示例：`user_lesson_progress_v1`  
- 单条建议字段：`textbook_version_id`, `grade`, `semester`, `lesson_key`（如 `rj:12` 或 `hint:识字2`）, `quiz_passed_at_ms`, `quiz_best_score`（若需要）, `follow_done_at_ms` 等。  
- **原则**：课级状态为**缓存型展示**；字级仍以 `USER_CHAR_PROGRESS` 为准。

### 1.5 进度在界面上的落点

| 位置 | 展示内容 | 优先级 |
|:---|:---|:---:|
| 课次字卡顶/底 | 已学字数 / 总字数、星星 | P0 |
| 单字角标「已学」 | `learned` | P0 |
| 课本同步学列表 | 可选：每课小测完成勾 | P1 |
| 「我的」学习报告 | 周/册汇总、常错字 TOP | P2 |

### 1.6 与跟读、听写的关系

- **跟读 / 听写**：偏过程与模仿（见跟读听写设计文档）；可写 `updated_at_ms` 或课级「已完成」标记，**是否自动升 mastered 由配置决定**，默认保守。  
- **小测**：偏**可量化的短时巩固**；与 `wrong_count`、`mastered` 绑定最直接，适合作为「掌握」的**可选触发条件之一**。

## 第二部分：课卡里的「小测」完整设计

### 2.1 产品定位

- **一句话**：本课生字范围内的**短闯关**（2～3 分钟），以**大按钮、听音/认形**为主，巩固「音—形」与简单笔顺，**不做长卷考试**。  
- **与笔顺页关系**：`stroke` 工具页的 `mode=test` 可作为**单字深度**补充；课次小测应以**多字、多题型串关**为主，二者可跳转互通，但**课测主页不应用单字笔顺页代替**（当前占位需替换）。

### 2.2 用户与场景

- **主用户**：幼儿～低年级儿童；家长可能在旁。  
- **入口**：`lesson.vue` 底部「小测」；建议跳转**专用页** `pages/literacy/lesson-quiz.vue`（命名示例），携带课次上下文（见 §2.8）。

### 2.3 题型设计（分阶段）

#### MVP（优先实现）

| 题型 ID | 玩法 | 单题时长 | 与进度 |
|:---|:---|:---|:---|
| `hear_pick` | 播读音（或带拼音），**3 选 1** 点汉字 | ~15～25 秒 | 对：`mastered` 或仅 `updated`；错：`wrong_count+1` |
| `see_pick_py` | 展示汉字，**2～3 个拼音/词语**选正确读音（可选） | 略长 | 同上 |

**单轮题量**：默认 **本课随机 5 字**（不足 5 则全用）；可配置 3/5/8。  
**通关条件**：MVP 建议 **≥4/5 对** 即「本课小测通过」，播庆祝动画 + 写课级 `quiz_passed_at_ms`（若启用 §1.4）。

#### v1.1

| 题型 ID | 玩法 |
|:---|:---|
| `stroke_order_light` | 笔顺填空 1～2 步（与 stroke 页共享判题逻辑更佳） |
| `distractor_same_radical` | 同部首干扰项二选一（大班+） |

#### 非目标（小测内不做）

- 长篇默写、限时打字、跨课混合竞赛排行榜。  
- 无音频时的「冷考」：无本地音则降级为「看字选义/描红」或跳过该题并记录。

### 2.4 交互与流程（主线）

```
进入小测 → 全屏/沉浸顶栏「本课小测」+ 始终「退出」
        → 第 1 题：大插图区 + 题干语音/短文字 + 2～3 选项（大）
        → 选对：短音效 + 贴纸飞入 + 自动下一题（可关「自动」由家长设）
        → 选错：不骂；再听一遍 / 轻提示后允许再选（最多 2 次尝试本题）
        → 最后一题 → 结算屏：星星/「本课小能手」+ 「再测一次」「回字卡」
```

**幼儿向细则**

- 每题**先播再可选**（可跳过播放入口给熟练孩子）。  
- 选项区高度 ≥ 建议触控最小 44pt 等价的 rpx。  
- 结算页**不强调分数**，可用「对了 X 个」+ 表情；分数给家长二级页。

### 2.5 出题与随机

- **字池**：当前 `lessonChars`（与人教 JSON 课次或 `lesson_hint` 一致）。  
- **随机种子**：可用 `lesson_key + date` 做「每日一版」可选；默认真随机即可。  
- **干扰项**：同课其它字优先；不足则同册同结构字（实现成本高则 MVP 仅用同课字）。

### 2.6 进度回写规则（建议默认）

| 事件 | `learned` | `mastered` | `wrong_count` |
|:---|:---:|:---:|:---|
| 小测单题答对 | 不变或策略开启时置 1 | 通关时可批量置 1（可选） | 不变 |
| 小测单题答错（最终错） | 不变 | 不变 | +1 |
| 本课小测通关 | 可选：本课所有参与字 `learned=1` | 可选：参与且从未错 `mastered=1`，错过的仅 `learned` | — |

**默认保守策略（推荐）**：通关只写课级完成 + 错题 `wrong_count`；**不自动**把未打开详解的字标 `learned`，避免家长误以为「孩子已认读」。

### 2.7 与现有代码的迁移路径

| 现状 | 目标 |
|:---|:---|
| `onMiniQuiz` 跳转 `stroke` 且仅首字 | 改为 `navigateTo` 课测页，参数携带 `rjLesson` 或 `hint` + **字列表编码**（建议 `encodeURIComponent(JSON.stringify(idsOrHanziList))` 长度受限时用 **storage 临时会话键** 传参）。 |
| 笔顺 `mode=test` | 保留为「单字深度测」或从小测结果页「这个字再练笔顺」跳转。 |

### 2.8 路由与参数（实现约定）

**推荐**

- `pages/literacy/lesson-quiz`  
- Query：`rjLesson=12` **或** `hint=识字2`；`from=lesson`  
- 字表：优先在 `lesson-quiz` 的 `onLoad` 内复用 `reloadLesson` 同源逻辑拉取；若重复请求重，可用 `uni.setStorageSync('lesson_quiz_payload', {...})` 跳转后立即读、读后删。

### 2.9 验收标准（摘要）

- 无字时小测按钮不可用或 toast，不崩溃。  
- 全程可一键回字卡；中途退出**仍保存**已答题的 `wrong_count`。  
- 离线：仅依赖本地音频与字表，无网可用。  
- Android 5+：题型 UI 无 `aspect-ratio` 单点依赖、触控区足够大（与课本页适配原则一致）。
