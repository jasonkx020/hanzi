## 二、色彩规范

| 用途 | 颜色名称 | 色值（HEX） | 说明 |
|:---|:---|:---|:---|
| **主色调** | 萌萌橙 | `#FFA726` | 暖橙，活泼、温暖，用于主要按钮、进度条、底部导航选中状态 |
| **辅色1** | 草芽绿 | `#8BC34A` | 清新有生机，用于正确反馈、勋章、鼓励信息 |
| **辅色2** | 天空蓝 | `#42A5F5` | 用于拼音模块、链接、辅助元素 |
| **强调色** | 蜜桃粉 | `#F48FB1` | 用于奖励提醒、勋章、女性化点缀 |
| **背景色** | 柔米白 | `#FFF8E7` | 主背景，护眼温和，不刺眼 |
| **卡片背景** | 纯白 | `#FFFFFF` | 凸出内容，加轻微阴影 |
| **深文字** | 深灰 | `#4E4E4E` | 正文、标题 |
| **浅文字** | 中灰 | `#9E9E9E` | 提示、辅助说明 |
| **错误/警告** | 暖红 | `#EF5350` | 答错提示、删除等 |

> **配色原则**：饱和度中等偏柔和，避免高饱和度刺眼。底色用米白+白色卡片，文字用深灰，确保对比度。橙色+绿色作为主辅搭配，符合“识字”主题（书本+自然）。

1. **纯白底 + 中间Logo（熊猫抱萌字）** → 0.5秒

3. **熊猫眨眼睛一次，汉语出现“汉字真有趣～”** → 0.5秒
