## 一、整体导航结构：底部四大金刚

底部固定一个**大圆角导航栏**，四个图标+文字，简洁明了，切换不迷路。

| 序号 | 标签名 | 图标（示意） | 核心功能 |
|:---:|:---|:---|:---|
| 1 | **识字** | 📖 一本打开的书 | 所有识字学习内容（课本同步、分级） |
| 2 | **拼音** | 🎵 小喇叭+声母韵母 | 拼音学习、拼读练习 |
| 3 | **查字** | 🔍 放大镜 | 查汉字（部首、拼音、笔画、组词） |
| 4 | **我的** | 👧 萌萌的头像 | 学习报告、设置、家长中心 |

> **为什么这样设计？**  
> 把最核心的两个学习功能（识字、拼音）直接放底部，符合家长和孩子的使用习惯。“查字”是刚需工具，“我的”用于管理和激励。四个选项不多不少，孩子容易记住。

## 二、首页：「识字」页面布局（重中之重）

首页默认就是 **“识字”** 页面，一打开App就能立刻开始学，不用找。

### 顶部区域（快速入口，左右滑动）
- **大横幅轮播图**：展示今日推荐课程 / 限时奖励 / 学习提醒（例如“完成3天打卡得勋章”）。
- **快捷切换年级**：一行圆角标签，左右可滑动。  
  `幼升小` `一年级上` `一年级下` `二年级上` `二年级下` … 默认显示“幼升小”或当前学习进度。

### 中间主体 — 三大学习模块（大卡片，一目了然）

采用 **竖排大卡片** 或 **2列网格**（取决于屏幕宽度）。建议用**大卡片**，每个卡片配一个可爱的动物/物品图标。

**卡片1：课本同步学**  
- 图标：📘 课本  
- 文案：**“跟着课本学生字”**  
- 副文案：人教版小学语文 1-6 年级  
- 点击后：进入按单元/课排序的生字列表，每一课有“认字”“写字”“跟读”“测试”。

**卡片2：趣味识字营**  
- 图标：🎈 气球 / 🧸 熊  
- 文案：**“边玩边记住”**  
- 副文案：动画识字 + 闯关游戏  
- 点击后：进入游戏化识字场景（例如“抓娃娃识字”“消消乐配对”）。

**卡片3：每日一练**  
- 图标：⭐ 星星 / 📅 日历  
- 文案：**“每天10个字”**  
- 副文案：智能推荐，复习弱项  
- 点击后：进入当日练习卡片（听音选字、看图识字、填空等）。

> 这三个卡片覆盖了“同步课内”、“趣味拓展”、“每日坚持”三大场景，家长会觉得功能完整又不复杂。

### 底部 — 学习进度条 + 激励信息
- 显示本周已学 **xx 个字**，距离目标还差 xx。  
- 一个小动物（比如一只叫“萌萌”的小熊猫）说话：“今天再学5个字，就能获得一枚荷叶勋章哦~”

## 三、第二页：「拼音」页面布局

专门用于**声母、韵母、整体认读音节**的学习。

### 顶部：拼音分类标签
`声母` `韵母` `整体认读` `拼读练习`，默认选中“声母”。

### 中部：23个声母以**彩色大按钮**排列（网格布局）
- 每个按钮上是一个声母（如 `b` `p` `m` `f` …），点击后：
  - 播放标准读音（女孩/童声）
  - 弹出卡片：包含该声母的儿歌、拼读示例（b-ā → bā）
  - 下方有“跟读”按钮，调用麦克风（需要权限）

### 韵母页同理，分为单韵母、复韵母、鼻韵母。

### 特色模块：「拼音大闯关」
- 一个独立的圆形大入口，点进去是“听音选字母”或“拼读小火车”游戏，增加趣味性。

---

## 四、第三页：「查字」页面布局

这是一个工具页，设计要**极简、响应快**。

- **顶部搜索框**：默认灰色提示文字“输入汉字，如‘萌’”
- 下方提供**手写输入**按钮（对于不会拼音的孩子）和**部首检索**按钮。
- 搜索结果区（以卡片形式展示）：
  - 汉字大字（带田字格）
  - 拼音、部首、结构、笔画数
  - 常用组词（2~3个）
  - 动态笔顺演示（动画）
  - “添加到生字本”按钮

为了更吸引孩子，可以加一个**“汉字小侦探”**小游戏：随机展示一个字的部分笔画，让孩子猜是什么字。

## 五、第四页：「我的」页面布局

这是家长控制 + 孩子成就感展示区。

### 顶部：头像 + 昵称 + 学习天数（例如“小美，已坚持12天”）

### 中间三大模块（大圆角卡片）：
1. **学习报告**  
   - 本周识字量 / 拼音掌握进度 / 薄弱字列表  
   - 曲线图（适合家长看）
2. **我的字库**  
   - 已掌握的字（可生成个性字卡）  
   - 待复习的字（按错误次数排序）
3. **勋章墙**  
   - 收集的勋章（如“连续7天打卡”、“拼音小英雄”），激发孩子动力

### 底部设置区：
- 年级设置
- 每天学习提醒时间
- 音效 / 朗读人切换（童声/标准女声）
- 护眼模式（定时休息提醒）
- 家长验证（防止孩子乱改设置）

## 六、视觉与交互特色（引人入胜的关键）

- **主色调**：暖橙色 + 草绿色 + 淡黄色，温暖、活泼、护眼。
- **字体**：圆体，字号偏大，行距宽。
- **角色IP**：一只戴眼镜的小熊猫，名叫“萌萌”，会出现在：
  - 加载动画（它翻书）
  - 答对题目时（它鼓掌）
  - 提醒休息时（它打哈欠）
- **音效反馈**：
  - 点击按钮 → “啵”一声（轻快）
  - 答对 → 小花或星星上升的音效
  - 答错 → 萌萌叹气并鼓励“再试一次”
- **动效**：卡片入场轻微弹性效果，按钮有点击缩放反馈。

## 七、一个典型的学习流程示例（直观感受）

1. 孩子打开App → 进入“识字”页 → 看到“课本同步学”大卡片。
2. 点击卡片 → 选择“一年级上” → 第一课《天地人》。
3. 进入课文字卡列表：`天` `地` `人` `你` `我` `他`。
4. 点击“天” → 出现全屏卡片：
   - 大字“天”
   - 动态笔顺
   - 跟读评分（萌萌鼓励）
   - 组词：“天空”“天气”
   - 最后一个小游戏：“找出卡片中所有的‘天’”。
5. 学完一课 → 获得3颗星 → 回到首页，进度条增长 → 萌萌跳出：“太棒啦！明天继续哦~”
6. 家长下班后打开“我的”里面的学习报告，看到孩子今天学了6个字，掌握了5个，1个需要复习。

## 八、总结：这个布局为什么有效？

| 设计原则 | 如何体现 |
|:---|:---|
| **直接了当** | 首页就是识字，底部导航只有4个，没有多余菜单 |
| **引人入胜** | 可爱的熊猫IP、游戏化任务、音效动画、勋章激励 |
| **家长放心** | 同步课本、学习报告、防沉迷设置、无私教陷阱 |
| **孩子爱用** | 大按钮、低挫败感（错误也有鼓励）、短时高频 |
