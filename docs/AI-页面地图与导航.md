## 2. 导航关系总览（文字版）

```
[Tab 识字] home
    ├→ navigateTo 课本同步学 textbook
    ├→ navigateTo 趣味识字营 game
    ├→ navigateTo 每日一练 daily
    ├→ navigateTo 会员 vip
    └→ navigateTo 教材与进度 curriculum

[Tab 拼音] pinyin/index
    ├→ navigateTo 拼音闯关 drill（占位）
    └→ navigateTo 家长管理 guardian

[Tab 查字] dictionary/index
    ├→ navigateTo 笔顺实验室 stroke（手写入口，非 OCR）
    └→ navigateTo 教材与进度 curriculum
    （查字结果在本页内嵌展示；从课次/字库跳转可走 char/detail → result）

[Tab 我的] me
    ├→ report / medals / curriculum / guardian / vip / stroke
    ├→ learned / wrong-often
    └→ 各子页返回栈返回 me

literacy/textbook → lesson → char/detail（中转）→ dictionary/result
literacy/textbook → lesson → lesson-follow | lesson-dictation | lesson-quiz
literacy/daily → char/detail → dictionary/result；可 switchTab 查字
me/learned | me/wrong-often → char/detail → dictionary/result

pages/learn/session：过渡页，引导进入 daily
pages/catalog/catalog：未在 pages.json 注册，仅代码内可跳转（与 textbook 类似的课次列表思路）
```

## 4. 与 AI 优化相关的备注

1. **自定义导航栏页面**（识字/拼音/查字/我的）：顶部安全区与标题需自行处理；优化时留意 `tab-root-page` 底部留白（避免被 Tab 遮挡）。  
2. **查字双轨**：`dictionary/index` 内嵌详情 vs `dictionary/result` 全页详情，改版时需保持信息架构一致或刻意区分角色（「快查」vs「深读」）。  
3. **占位页**：`literacy/char`、`pinyin/drill` 适合作为「即将上线」营销或骨架屏实验场。  
4. **儿童向**：首页、气球营、课次字卡大量使用 emoji 与短句；优化时保持语气一致、触控目标足够大。  
5. **主题色**：全局 CSS 变量见 `static/styles/app-theme.css`（`--meng-*`），改版时优先改令牌而非散落的 hex。
