# 课次字卡：跟读模式与听写模式 — 产品设计说明

> **文档目的**：锁定「课本同步 → 课次字卡」场景下**跟读 / 听写**的产品主线与幼儿向体验标准，供需求评审、交互实现与回归测试对照，避免功能膨胀偏离学龄前～低年级的核心目标。  
> **关联主线**：与 `docs/原始设计.md` 中「识字 · 课本同步学」「大按钮、低挫败感」一致；实现入口见 `pages/literacy/lesson.vue`（跟读 / 听写 / 小测按钮及后续独立页）。

---

## 1. 范围与非目标

### 1.1 范围内

| 场景 | 说明 |
|:---|:---|
| 入口 | 从「课本同步学」进入某课，在**课次字卡页**进入跟读或听写（可拆为独立子页）。 |
| 用户主画像 | **幼儿～低年级**：注意力短、识字量有限、需要「听—看—动」节奏清晰；常由家长在旁陪同。 |
| 字源 | 与当前课次一致：人教同步 JSON 课次字表，或 `lesson_hint` 字库；顺序默认与字卡列表一致。 |

### 1.2 非目标（刻意不做或后置）

| 非目标 | 原因 |
|:---|:---|
| 专业语音学/音素级纠音课堂 | 与「萌萌识字」启蒙定位不符；技术复杂度高，易喧宾夺主。 |
| 长时间书写、大量田字格听写 | 不符合幼儿手部发育与单次使用时长；与「低挫败」主线冲突。 |
| 强排名、排行榜、与陌生人对比 | 增加焦虑，偏离亲子与自我进步叙事。 |
| 在字卡同一屏堆满控件与说明 | 字卡以「点字学、点拼音听」为主；模式进入**专用流程页**更清晰。 |

---

## 2. 设计原则（幼儿向 · 可检查清单）

实现或改需求时，应满足下列多数项；冲突时以**标粗**为优先。

1. **字少、图大、一步一事**：单屏说明不超过一行短句；主操作只有一个「当前动作」。
2. **先示范后模仿**：默认先自动播放标准音（字/词/拼音按产品定义），再邀请孩子动作。
3. **低挫败**：错误不羞辱；阶梯提示（再听一遍 → 轻提示 → 揭晓答案）；允许跳过、返回字卡。
4. **短时高频**：单轮建议 **3～5 个字**为一组，「再来一组」扩展；避免一次练满全课。
5. **家长可控敏感能力**：录音、评分、上传等默认**关或弱**；在设置/家长区显式开启。
6. **文案避压**：少用「考试」「听写」「必须」；多用「听一听」「说一说」「找一找」等游戏化表达。
7. **与主线一致**：不替代「点进单字详解」的深度学习；模式是**课的巩固层**，不是第二套课表。

## 3. 跟读模式

### 3.1 产品目标

- 巩固 **字音 ↔ 字形** 联结，以**模仿与节奏**为主。  
- 让孩子觉得「我在跟着萌萌/课本一起读」，而不是「在被评测」。

### 3.2 推荐流程（主线）

```
进入跟读 → 展示本组第一个字（大） → 自动播读音（可含拼音格同步高亮）
       → 短提示「你也说一说」→ 【可选：按住录音 / 点「下一个」只听不说】
       → 正向反馈（贴纸/音效/简短口头语）→ 下一字 → 组结束可「再来一组」/「回字卡」
```

### 3.3 交互要点

| 项 | 建议 |
|:---|:---|
| 默认顺序 | 与课内生字顺序一致；可选「只练未学」缩短路径（设置或二级入口）。 |
| 录音 | **大「按住说」**优于「点一下开始」；松开结束；无录音权限时降级为「只听跟读 + 点下一个」。 |
| 反馈 | 幼儿界面**弱化分数**；可用「再试一次也很棒」+ 简单二档（像/再试试）；技术评分仅家长端可选看。 |
| 进度 | 用**脚印、小火车节数**等图形进度，数字为辅。 |
| 退出 | 全程可见 **「回字卡」**，避免幼儿困在流程内。 |

### 3.4 验收标准（摘要）

- 无麦克风权限时流程仍完整、不白屏、不反复弹窗骚扰。  
- 单字环节从示范到可交互不超过 **2 次点击**（不含系统授权）。  
- 任意一步 **3 秒内** 有视觉或语音「下一步该干什么」的提示。

## 4. 听写模式

### 4.1 产品目标

- 巩固 **听音辨形**；幼儿阶段**明显轻于**传统课堂「默写整词」。  
- 以**选择辨认**为主，**轻描/书写**为辅且可后置。

### 4.2 分级（建议主线：先做 A，B/C 迭代）

| 级别 | 形式 | 适用 |
|:---|:---|:---|
| **A · 听音点字（MVP）** | 播放读音后，从 **2～3 个大字卡**中点选正确字。 | 小班～中班为主，主线优先实现。 |
| **B · 轻描/描红** | 在轮廓或笔顺引导下跟写 1～2 笔或描红整字（短时）。 | 大班～一年级，需评估书写疲劳。 |
| **C · 田字默写** | 接近课内听写；仅对高年级或家长显式开启。 | 与「幼儿主线」弱绑定，防偏离。 |

### 4.3 节奏与提示阶梯

- 每字：读 **1～2 遍** → 留白时间**长于成人直觉 1～2 秒** → 再判题或下一题。  
- 第一次错：再播一遍音。  
- 第二次错：轻提示（正确字轮廓闪动或部首色块）。  
- 仍错：**直接展示正确字**并进入下一题，**不循环惩罚**。

### 4.4 文案与命名

- 界面主标题倾向：**「小耳朵找字」「听一听，点哪个」**；避免单独大字「听写」。  
- 与跟读区分：**跟读 = 开口模仿**；**听写（幼儿版）= 听音辨认（点选）**。

### 4.5 验收标准（摘要）

- MVP 仅 A 时，全程无需键盘输入汉字。  
- 每题从播完音到可点选，等待窗长可配置，默认偏长（幼儿友好）。  
- 错误路径必有**非负面**动效或语音，禁止嘲讽类文案/音效。

## 5. 与小测的关系

| 维度 | 建议 |
|:---|:---|
| 定位 | **小测**偏「短闯关、略游戏化」；跟读偏「说」、听写（幼儿版）偏「听辨」。 |
| 入口 | 字卡上三入口可并存，但**视觉权重**：跟读、听写 ≥ 小测；或把小测收进「更多」避免并列三选困难。 |
| 顺序建议 | 同一课内推荐顺序：**自由点字 → 跟读 → 听音点字 → 小测**（由易到难，可跳过）。 |

**进度与小测实现细则**（已学/掌握/错题、题型、回写规则、路由）：见 [课次字卡-学习进度与小测设计.md](./课次字卡-学习进度与小测设计.md)。

## 6. MVP 与迭代阶段（防偏离路线图）

| 阶段 | 跟读 | 听写 | 备注 |
|:---|:---|:---|:---|
| **MVP** | 自动逐字播 + 大「下一个」+ 可选「按住说」（录音默认关或由家长开） | 仅 **A：三选一 点字** + 提示阶梯 | 先跑通一课一组 3～5 字 |
| **v1.1** | 进度图形化、「只练未学」 | 留白时长可配、组大小可配 | 设置进家长区 |
| **v1.2** | 家长端可看简单跟读报告（非幼儿主屏） | 评估 **B：轻描** | 需单独 UX 与性能评估 |
| **远期** | 与课标/校本扩展弱耦合即可 | **C：默写** | 严格控入口，避免幼儿主流程被占满 |

**偏离预警**：若某版本把「默写打分、排行榜、长篇章听写」做进幼儿默认路径，视为与本设计冲突，需单独评审。
