## 三、口播与录制规范

| 项目 | 建议 |
| --- | --- |
| 人设 | 女童声或软萌童声，语速偏慢，句末略上扬 |
| 时长 | 单条 2～6 秒为宜，最长不超过 8 秒 |
| 文件 | `{id}.opus`，与表中 id 完全一致（小写、下划线） |
| 命名 | 勿改 id，仅替换音频；改文案需同步改代码常量与本文档 |
| 冲突 | 与生字读音同时播放时：课次听写/再听等用 `utils/lesson-mode-audio.js` 串行（提示 `onEnded` 后再播读音）；`playMengmengVoice` 已全局排队，勿用固定 `setTimeout` 估时长 |
| 编排 API | `playLessonHintThenTargetReading`（提示+生字）、`playLessonReplayThenTargetReading`（再听+生字）、`playLessonTargetReadingAfterVoice`（等提示结束再生字） |
